# 👓 Smart Hearing Glasses – Real-Time Speech Transcription System

Overview

Smart Hearing Glasses is an assistive system designed to help people with hearing impairments communicate more easily in real life.

The system captures surrounding speech, converts it into real-time text using a Flutter mobile application, and sends the processed data to an ESP-based smart glasses display.



## 🚀 Features
🎤 Real-time speech-to-text transcription
📱 Flutter-based mobile application
🔵 Bluetooth communication with ESP device
👓 Live text display on smart glasses
⚡ Fast and lightweight processing

## 🛠️ Tech Stack
Frontend: Flutter
Speech Recognition: Speech-to-Text APIs
Hardware: ESP32 + OLED Display
Communication: Bluetooth (Serial)

## 🧠 How It Works
The mobile app listens to speech using the microphone
Speech is converted into text in real time
The text is sent via Bluetooth to the ESP32
The ESP32 displays the text on an OLED screen attached to the glasses
